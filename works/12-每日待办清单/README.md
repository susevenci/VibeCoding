# 12 · 每日待办清单

第 12 讲实战产出：每日待办清单。单文件 HTML，打开即用，数据存在浏览器 `localStorage` 里。

## 文件

| 文件 | 说明 |
|---|---|
| `todo.html` | 每日待办清单（单文件应用） |

## 功能

- 添加 / 完成 / 删除待办
- 顶部显示今天日期与「今天还有 N 件事」计数，日期每分钟自动刷新
- 「清除已完成」批量清理
- 空列表时显示手札风提示
- 移动端响应式（断点 480px）

## 技术要点

- `localStorage` 键：`todos`（数组，`{ text, completed }`）
- 用户输入经 `innerHTML` 渲染前走 `escapeHtml()` 转义
- 手札风视觉：暖纸底色 + 手写体标题

## 复现

```bash
start todo.html
```
